# Implementation Plan: Keyboard Shortcuts

**Branch**: `019-keyboard-shortcuts` | **Date**: 2025-11-16 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/019-keyboard-shortcuts/spec.md`

## Summary

Add comprehensive keyboard shortcuts to Skill Debugger to improve productivity and accessibility for keyboard-first users. Implements 6 primary shortcuts (Cmd/Ctrl+F for search, Cmd/Ctrl+1-6 for tab switching, arrow keys for list navigation, Enter for selection, Escape for clearing, Cmd/Ctrl+/ for help). Technical approach uses React custom hook (`useKeyboardShortcuts`) for centralized event handling, accessibility-focused design with ARIA live regions, and cross-platform modifier key detection (Cmd on macOS, Ctrl on Windows/Linux). All implementations follow TDD methodology with 100% test coverage target.

### 1. Data Model (`data-model.md`)

**Entities**:

- **KeyboardShortcut**
  - `id`: Unique identifier (e.g., "search-focus")
  - `key`: Physical key (e.g., "f", "1", "ArrowDown")
  - `modifiers`: Array of modifiers (e.g., ["ctrl"], ["cmd"])
  - `description`: User-facing description
  - `category`: Grouping (e.g., "Navigation", "Search")
  - `handler`: Callback function
  - `condition`: Optional function to determine if shortcut is active

- **KeyboardEvent** (TypeScript interface)
  - `key`: string
  - `metaKey`: boolean (Cmd on macOS)
  - `ctrlKey`: boolean (Ctrl on Windows/Linux)
  - `shiftKey`: boolean
  - `altKey`: boolean
  - `target`: EventTarget

- **FocusState**
  - `activeElement`: HTMLElement | null
  - `previousElement`: HTMLElement | null

**State Transitions**:

```
Search Field Focus:
  Idle → Cmd/Ctrl+F pressed → Search Focused → Text Selected

Tab Switching:
  Tab N → Cmd/Ctrl+M pressed → Tab M (if valid) → Content Rendered

Skill Navigation:
  Skill[i] Focused → ArrowDown → Skill[i+1] Focused → Visual Update
```

### 2. API Contracts (`contracts/`)

**File**: `contracts/useKeyboardShortcuts.ts`

```typescript
/**
 * Custom React hook for managing keyboard shortcuts
 *
 * @returns {KeyboardShortcutsHook} Hook interface
 */
export interface KeyboardShortcutsHook {
  /**
   * Register a keyboard shortcut
   *
   * @param shortcut - Shortcut configuration
   * @example
   * registerShortcut({
   *   key: 'f',
   *   modifiers: ['ctrl', 'cmd'],
   *   handler: () => searchInput.current?.focus(),
   *   description: 'Focus search',
   *   category: 'Search'
   * })
   */
  registerShortcut: (shortcut: KeyboardShortcut) => void;

  /**
   * Unregister a keyboard shortcut
   *
   * @param id - Shortcut identifier
   */
  unregisterShortcut: (id: string) => void;

  /**
   * Check if a shortcut is currently active
   *
   * @param id - Shortcut identifier
   * @returns True if shortcut is registered and active
   */
  isShortcutActive: (id: string) => boolean;

  /**
   * Get all registered shortcuts grouped by category
   *
   * @returns Map of category to shortcuts
   */
  getAllShortcuts: () => Map<string, KeyboardShortcut[]>;
}

export interface KeyboardShortcut {
  id: string;
  key: string;
  modifiers: Modifier[];
  handler: (event: KeyboardEvent) => void;
  description: string;
  category: ShortcutCategory;
  condition?: () => boolean;
}

export type Modifier = 'ctrl' | 'cmd' | 'shift' | 'alt';
export type ShortcutCategory = 'Navigation' | 'Search' | 'Selection' | 'Help';
```
